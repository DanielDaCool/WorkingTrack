# Apps Script - שעות עבודה מהאפליקציה

שני הקבצים חיים באותו פרויקט Apps Script, הצמוד לגיליון "שעות עבודה מהאפליקציה".

## מה כל קובץ עושה

- `appBackend.gs` - אפליקציית ווב:
  - `doGet` מחזיר את רשימת המקומות מהגיליון `Places` (עמודה A).
  - `doPost` מקבל שיעור גמור מהאפליקציה ומוסיף שורה ל-`Shifts`, כולל נוסחת "חישוב משכורת" בעמודה L.
  - `setupDataValidation` מגדיר רשימה נפתחת של מקומות בעמודה D של `Shifts`.
  - `isFrcShift` מוגדר רק כאן, ו-`sync.gs` משתמש בו.
- `sync.gs` - מעתיק שורות מ-`Shifts` לגיליון הדיווח "דיווח פעילות 2026-2027" (קובץ של איריס, הכתיבה אליו נעשית מהסקריפט בלבד). יומן ההרצות נכתב ללשונית `יומן סנכרון`.

## התקנה

1. פתח את הגיליון "שעות עבודה מהאפליקציה".
2. Extensions > Apps Script.
3. הדבק את `appBackend.gs` ואת `sync.gs` כשני קבצים נפרדים בפרויקט. שמור.
4. רענן את הגיליון. יופיע התפריט "סנכרון דיווח".

## אחרי עריכת appBackend.gs

חובה לפרוס מחדש כגרסה חדשה של הפריסה הקיימת, כדי שכתובת ה-URL שהאפליקציה משתמשת בה לא תשתנה:
Deploy > Manage deployments > עיפרון (Edit) > Version: New version > Deploy.
לא ליצור New deployment, כי זה מייצר כתובת אחרת.
שינוי ב-`sync.gs` בלבד לא דורש פריסה מחדש.

## הוספת מקום

1. הוסף שורה ב-`Places` (עמודה A).
2. הוסף את אותו שם בדיוק ל-`PLACE_MAP` ב-`sync.gs` (יישוב, בית ספר, כיתה).
3. הרץ ידנית `setupDataValidation` מעורך הסקריפטים, כדי שהרשימה הנפתחת ב-`Shifts` תכלול את המקום.

## תפריט "סנכרון דיווח"

- בדיקה בלבד (לא כותב כלום) - מריץ הכול ורושם ל-`יומן סנכרון` בלי לכתוב ליעד. מומלץ להריץ ראשון.
- סנכרן עכשיו - כותב ליעד.
- הפעל סנכרון יומי אוטומטי - יוצר טריגר יומי (שעה ב-`CONFIG.DAILY_SYNC_HOUR`, ברירת מחדל 23:00). בהרצה הראשונה יתבקש אישור הרשאות.
- בטל סנכרון יומי אוטומטי - מוחק את הטריגר.

## תעריפי שעה

נמצאים בגיליון `Shifts`, לא בקוד:
- `P1` - תעריף FLL/רגיל (כרגע 100).
- `P2` - תעריף FRC (כרגע 80).

סה"כ משכורת: `Shifts!M2` (`=SUM(L:L)`).

## כללי חישוב

- חיוב לקוח (עמודה L ביעד) = שעות העבודה מעוגלות לרבע שעה. בשיעור FRC (המקום או סוג המפגש מכילים "frc") = מחצית מהשעות, מעוגלת לרבע שעה.
- בפועל (עמודה M ביעד) = כל השעות, מעוגלות לרבע שעה.
- "ריק" או תא ריק במקור נשארים ריקים ביעד.
- נוסחת המשכורת ב-`Shifts` עמודה L משתמשת באותו כלל (חצי שעות ב-FRC) כפול התעריף המתאים.
